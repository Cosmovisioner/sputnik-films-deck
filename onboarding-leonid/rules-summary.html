Cult Group · sales

Коммерческие правила · за 2 минуты

Краткая версия для онбординга. Полный документ — по ссылке внизу.

Роль

  1. Ты — охотник: входящие + тёплая база → бриф до договора; массовый холод — только после плана с CRO (день 8). Не продакшен, не PR.
  2. Самоорганизация: если чего-то не хватает, идёт не так, нужен слот/доступ — или видишь лишнее — скажи и сделай следующий шаг сам (написать, назначить звонок, пушнуть). Не ждать, пока спросят.
  3. Клиент покупает группу — Cult, Blaster, Sputnik — одна точка входа.
  4. KPI = квалифицированные лиды (бриф + скоринг ≥ 5), не «красивые созвоны».
  5. Handoff = договор + предоплата → продюсер юнита. Ты остаёшься наблюдателем.
  6. Не исчезай после КП — веди до handoff.

Ритм

  • Каждую пятницу · 12:00 — звонок юнитов по продажам. Лидируете: Дима + Лёня. Отчёты, разбор сделок, блокеры. Это регулярный ритм.
  • Daily async CRO — блокеры 1–3 строками, сам инициируешь.

Холод · актуальные поводы (с CRO)

  1. Cast Dev → TG Кости Мельникова: предложить клиенту короткое интервью / каст-дев для канала Кости — мягкий повод без жёсткого sell.
  2. «Робот и сыновья» как троян: бесплатный МК / лекция / вебинар про нейросети, автоматизацию и агентизацию — для холодной и тёплой базы; договориться с юнитом R&S.

Массовый холод — не неделя 1. Сначала тёплая база, потом план волны 2 с CRO (день 8).

ICP · наш клиент (5 проверок)

  1. Прямой клиент (бренд/заказчик), не агентство в первом приоритете
  2. Средний и крупный бизнес, Россия + СНГ
  3. Задача в Cult / Blaster / Sputnik, не стоп-лист
  4. Бюджет выше порога юнита или OK Сергея на неформат
  5. Не казино, букмекеры, алкоголь, политика — на новый холод

Исключение: бренды уже в тёплых пулах юнитов (напр. WINLINE у Cult, Фонбет у Blaster) — это существующие отношения хэда. Не перехватывать и не открывать новый холодный беттинг без OK CRO. Агентства в пулах Blaster = тёплые/партнёрские, не ICP для массового холода.
