Коммерческие правила · кратко

Короткая версия для онбординга. Полный документ — по ссылке внизу.

Роль

  1. Ты — охотник: входящие + тёплая база → бриф до договора. Не продакшен, не PR.
  2. Самоорганизация: не хватает доступа / слота / ясности — скажи и сделай следующий шаг сам.
  3. Клиент покупает группу — Cult, Blaster, Sputnik — одна точка входа.
  4. KPI = квалифицированные лиды (бриф + скоринг ≥ 5).
  5. Handoff = договор + предоплата → продюсер юнита.
  6. Не исчезай после КП — веди до handoff.

Ритм

  • Пятница · 12:00 — звонок юнитов по продажам. Лиды: Дима + Лёня.
  • Конец каждого дня — короткий отчёт CRO: что сделал, что закрыто, что мутно.
