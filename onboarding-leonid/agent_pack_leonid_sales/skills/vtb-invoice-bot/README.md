# VTB Invoice Bot Skill

Автоматизация выставления счета из шаблона Google Docs `ШАБЛОН_СЧЕТ_ВТБ`.

Используется вместе с:
- `60_System/automation/drive_automation.py`
- договором клиента (`.pdf/.docx/.md`)
- правилом имени: `СЧЕТ_<номер>_<дата>_<контрагент>`

Основная инструкция находится в `SKILL.md`.
