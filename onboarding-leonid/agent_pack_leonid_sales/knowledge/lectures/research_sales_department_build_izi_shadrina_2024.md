## 2. Команда

### 2.1. Продажи vs реализация / сервис

На слайде явное разделение зон: **продажи** отдельно от **реализации/сервиса**. Для студии: кто **закрывает контракт и ведёт воронку** vs кто **исполняет проект** — границы и handoff должны быть прозрачны (см. также SETTERS: передача в реализацию).

### 2.2. Зона менеджера по продажам (чеклист со слайда)

- поиск клиентов;  
- ведение базы;  
- звонки;  
- подготовка КП;  
- встречи;  
- мероприятия: вебинары, выставки, конференции;  
- **продажи + апсейл + продления + сбор оплат**.

*Для микрокоманды часть пунктов может быть на фаундере — важно не смешивать бесконечно без регламента.*

### 2.3. Найм (этапы)

- HR-скрининг;  
- подготовка **кейса**;  
- **ролевая игра**;  
- интервью.

### 2.4. Качества сейлза (soft)

- нацеленность на **результат**;  
- **ответственность**;  
- **клиентоориентированность**.

### 2.5. Hard skills

На слайде — «чек-лист» без раскрытия в тексте PDF; на практике дополнять под продукт: воронка, CRM, презентация, переговоры, работа с возражениями, понимание экономики сделки.

## 3. Метрики

### 3.1. Плановые уровни

- выполнение **плана по выручке** (факт / потенциал);  
- **KPI** по **фокусным продуктам** и **качеству** (как на слайде — детали визуальные).

### 3.2. Операционные метрики (ориентиры со слайда)

| Метрика | Ориентир |
|---------|-----------|
| Звонки | ~**30 в день** |
| Встречи | **1 в день** |
| Конверсия | отслеживать по воронке |
| Средний чек | мониторинг |
| Цикл сделки | мониторинг |
| Потенциал по сделкам | прогноз взвешенного пайплайна |

*Цифры звонков/встреч — типовой ориентир из деки; для премиального продакшена и длинного цикла пересобирать под ICP.*

## 4. Система мотивации

### 4.1. Совокупный доход

**Оклад + % + KPI.**

- **Оклад** — закрывает базовые потребности.  
- Ориентир по рынку на слайде: **миддл (Москва) ~80–120 тыс.** (на момент деки; индексировать под год и регион).

### 4.2. Премиальная часть

- **% от новых продаж** (от выручки, на слайде **~8–10%**);  
- **% от прочих продаж** (апсейл / продления, **~1–2%**);  
- **фикс с продажи фокусных продуктов** или **прогрессивная шкала**.

### 4.3. Порог выплаты премии

- **Пороговое значение для выплаты премии — 80%** (выполнение плана или согласованного показателя — как зафиксировано в регламенте).

## 5. Процессы

### 5.1. Входы для планирования

Учитывать при построении плана:

- **база**;  
- **сезонность**;  
- **обороты**;  
- **индустрии**;  
- **маркетинговые инфоповоды**;  
- **бюджеты** клиентов.

### 5.2. Планирование выручки

- план по выручке с учётом **потенциала по наработкам**, **отвалов**, **инсайтов с рынка**;  
- горизонт: **месяц / квартал / иногда год**;  
- план **спускается не позднее чем за 2 недели до начала периода**;  
- **планы и факты прозрачны** по отделу и **на общих приборах** (дашборды, общие доски).

### 5.3. Дисциплина плана

- план **зафиксирован, опубликован**, все **подтвердили получение**;  
- **регламент** «что и как засчитывается» в выполнении плана;  
- планирование начинается **заблаговременно**;  
- **отпуск и больничный не влияют на план** (норма из деки — значит нормируется нагрузка/ресурс иначе, а не «рвём план молча»).

### 5.4. Регулярные встречи

**Индивидуальные:**

- **1:1 раз в неделю**;  
- цели на квартал;  
- итоги квартала;  
- итоги полугодия.

**Командные:**

- планёрка;  
- промежуточный синк;  
- встреча по итогам месяца;  
- встреча по итогам квартала.

**Общие (компания):**

- инфообмен **раз в неделю**;  
- общая встреча по итогам месяца / квартала.

### 5.5. Повестка планёрки (со слайда)

- командные результаты по **плановым значениям и метрикам**;  
- менеджеры — о **личных результатах и потенциале**;  
- **лучшие / отстающие**;  
- ответственные за метрики и активности — о результатах команды;  
- обмен опытом, **лучшие практики, кейсы**;  
- **план активностей на неделю**, коммиты;  
- обучение;  
- вопросы.

### 5.6. Повестка 1:1

- текущие результаты по плану и метрикам;  
- **потенциал**;  
- результаты активностей с **прошлой** недели;  
- план активностей и **цели на эту неделю**;  
- **ключевые клиенты и кейсы**;  
- вопросы.

### 5.7. Развитие текущих клиентов

- регулярная коммуникация: **минимум 3 касания в месяц**;  
- почта: **кейсы, аналитика, анонсы, спецусловия**, релевантные инфоповоды;  
- личные встречи **раз в квартал**;  
- вебинары / семинары;  
- бизнес-завтраки;  
- неформальные встречи, поздравления, подарки;  
- мероприятия, вечеринки.

*Пересечение с саммари лекции пользователя по долгим отношениям и с [artifact_sales_lecture_crm_negotiations_relationships_2026](../../40_Artifacts/artifact_sales_lecture_crm_negotiations_relationships_2026.md).*

### 5.8. Ревью сотрудника

- цели на квартал / полугодие;  
- ожидаемая оценка;  
- плановые показатели;  
- развитие;  
- доп. ответственность;  
- подведение итогов;  
- линейка **старший / ведущий** (рост внутри команды).

## 6. Инструменты

### 6.1. CRM — стадии в работе (со слайда)

- в работе;  
- знакомство;  
- презентация;  
- согласование;  
- закрытие сделки.

*Согласовать с фактической воронкой Amo / процессом студии.*

### 6.2. Полезное для сейлзов (контур enablement)

- **банк возражений**;  
- **скрипты по продуктам** (свойства → преимущества → выгоды);  
- общий **sales kit**;  
- **готовые офферы** под каждый продукт;  
- скрипты **постмитов / постколлов**.
