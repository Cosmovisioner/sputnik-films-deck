Стартовый набор для онбординга (не полный SB-банк). Живые формулировки с звонков — пополняй через Диму / meeting-report. Полный файл — в agent-pack.

ВозражениеОтработка (черновик)
«Дорого / какой бюджет?»Рамка 2 вариантов под цель; 2–3 уточнения → диапазон. Не средняя температура.
«В следующем квартале»Зафиксировать дату возврата в Amo + что изменится к кварталу. Не спорить с календарём.
«Сделаем сами / in-house / на iPhone»Где in-house ок; где нужен продакшен (масштаб, риск, дедлайн). Не унижать команду клиента.
«Уже есть подрядчик»Не выбивать; предложить second opinion / пилот на юнит. Internal first внутри группы.
«Пришлите КП без брифа»Brief-gate: без полей КП = шум. Чеклист полей → потом смета.
«Нужно вчера»Честно по слоту юнита; иначе отказ или урезанный scope. Не обещать за хэда.
«Почему не агентство?»ICP: прямой клиент в приоритете; агентства — тёплые/партнёрские по правилу CRO, не массовый холод.
«А Sputnik умеет?»«Берём» решает Сергей. Не тащить всё в Sputnik по привычке.
«Скиньте все презентации»Deck-router: неясно → Cult Group; явный юнит → преза хэда.
«Напишите Хомичу / в Prodavan»С 01.08 Хомича нет. CRM и доступы — только через Диму.
